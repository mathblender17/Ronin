# Leap Card Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** From the recap view, suggest up to three "Wait, WHAT?" leaps (root question → a visited node) ranked by embedding drift, let the user edit one, and download it as a 1080×1350 PNG.

**Architecture:** A pure scoring module (`backend/leaps.py`) ranks root→visited-node paths from embedding vectors. `backend/ai.py` gains an embedding call and a structured copy-writing call that go through the existing provider layer. One endpoint wires them together with no new tables. The frontend draws the card with Canvas 2D in one function shared by the preview and the export.

**Tech Stack:** FastAPI, SQLAlchemy, Pydantic 2, google-genai (`gemini-embedding-001`), pytest; React 19 + TypeScript, Canvas 2D. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-25-leap-card-design.md`

## Global Constraints

- No new Python or npm dependencies. No new database tables or columns.
- Eligible end node: `explored_at` set and depth ≥ 2 (root depth 0, first-level depth 1).
- `score = end_distance × weakest_hop`, with `end_distance = 1 − cos(root, node)` and `weakest_hop = min cos(parent, child)` over the path. Vectors are mean-centred over the trail first. No depth term.
- Shortlist size: at most 3, spread across first-level branches while other branches remain.
- Embedded text per node: `title + ". " + summary`. Embedding model: `gemini-embedding-001`.
- Copy limits: `hook` ≤ 12 words, `reframe` ≤ 25 words, `waypoints` 2–3 titles taken from the path's interior.
- Card: 1080×1350 px. Masthead text `RONIN · A LEAP`. Labels `Started with:`, `Ended at:`, `interpretation`. Footer `N hops · M subjects crossed`. Filename `ronin-leap-<slug>.png`.
- Ineligible-trail copy: `Go one layer deeper to find a leap.`
- The endpoint calls `_require_writable()` (403 in read-only). The button is hidden in read-only mode.
- Every commit message ends with the `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` line.
- `# shortcut: re-embeds every request, add a node_embeddings cache if latency hurts.` goes on the embedding call site in `main.py`.

**Deviation from spec, decided here:** with a `node_id` body, the endpoint skips embeddings entirely and returns `ranked: false` with `score: null`. Scoring a single user-chosen path tells the user nothing, and skipping it saves a call. So `score` is `float | None`.

## Review Focus

- A trail where centring leaves a zero vector (for example, two nodes with identical text) must not divide by zero. `cos` returns 0.0 for a zero-norm vector. Test this in Task 1.
- The LLM returns fewer leap entries than paths sent, or duplicate or out-of-range `index` values. Candidates without valid copy are dropped. If none survive, the endpoint returns 503, not 500. Test this in Task 3.
- The LLM returns waypoint titles with different case or spacing from the stored titles. Matching is exact after `" ".join(t.split())`, with no fuzzy matching, and the middle-node fallback applies. Test this in Task 2.
- Long root questions or hooks overflow the canvas. `wrapLines` truncates with `…` at the line limit. This gets checked by eye in the Task 6 browser step with a 500-character question.
- `node_id` points at another trail's node, at the root, or at an unvisited node. All return 400. Test this in Task 3.

### Task 1: Pure leap scorer

**Files:**
- Create: `backend/leaps.py`
- Test: `backend/tests/test_leaps.py`

**Interfaces:**
- Produces:
  - `@dataclass(frozen=True) class TrailNode: id: str; parent_id: str | None; title: str; summary: str; domain: str; explored: bool`
  - `@dataclass(frozen=True) class ScoredPath: node_id: str; path: list[str]  # node ids, root first; end_distance: float; weakest_hop: float; score: float`
  - `def path_to(nodes: dict[str, TrailNode], node_id: str) -> list[str]`: ids from root to `node_id`
  - `def eligible_ids(nodes: dict[str, TrailNode]) -> list[str]`: explored nodes with depth ≥ 2, in dict order
  - `def score_paths(nodes: dict[str, TrailNode], vectors: dict[str, list[float]]) -> list[ScoredPath]`: every eligible path, score descending. Centres `vectors` by their mean before computing.
  - `def shortlist(scored: list[ScoredPath], k: int = 3) -> list[ScoredPath]`
  - `def embed_text(node: TrailNode) -> str`: returns `f"{node.title}. {node.summary}"`

### Task 3: Leaps endpoint

**Files:**
- Modify: `backend/main.py` (new route after `expand_node`)
- Test: `backend/tests/test_api.py` (append)

**Interfaces:**
- Consumes: Task 1's `TrailNode`, `eligible_ids`, `path_to`, `score_paths`, `shortlist` and `embed_text`. Task 2's `ai.embed_texts`, `ai.generate_leap_copy`, `LeapRequest` and `LeapsOut`.
- Produces: `POST /api/rabbit-holes/{hole_id}/leaps`, request `LeapRequest | None`, response `LeapsOut`.

The flow is:
1. `_require_writable()`
2. `_load_hole`
3. Build `dict[str, TrailNode]`.
4. If there are no eligible ids: 400 with `Go one layer deeper to find a leap.`
5. If `node_id` is given: 400 when it isn't eligible (`That node can't anchor a leap yet.`). Otherwise use a single path with `score=None` and `ranked=False`.
6. Otherwise: `ai.embed_texts` over every node. On `AIServiceError`, return `{"ranked": false, "candidates": []}`. Then `shortlist(score_paths(...))`.
7. `ai.generate_leap_copy`. On `AIServiceError`, return 503 with `str(exc)`.
8. Map the copy to paths by `index`, ignoring out-of-range or duplicate indexes. If none map: 503 `Ronin couldn't write this leap. Please retry.`
9. Set `hops = len(path) - 1` and `domains = len({n.domain for n in path nodes[1:]})`.

### Task 5: Card renderer and API client

**Files:**
- Modify: `src/types.ts`, `src/api.ts`
- Create: `src/leapCard.ts`

**Interfaces:**
- Produces:
  - In `types.ts`: `export type LeapCandidate = { node_id: string; path: string[]; waypoints: string[]; hook: string; reframe: string; score: number | null; hops: number; domains: number }` and `export type Leaps = { ranked: boolean; candidates: LeapCandidate[] }`
  - In `api.ts`: `leaps: (id: string, nodeId?: string) => request<Leaps>(...)`, a POST with the body `nodeId ? { node_id: nodeId } : {}`
  - In `leapCard.ts`:
    - `export const CARD_WIDTH = 1080, CARD_HEIGHT = 1350`
    - `export type LeapCardData = { question: string; end: string; waypoints: string[]; hook: string; reframe: string; hops: number; domains: number }`
    - `export function wrapLines(ctx: CanvasRenderingContext2D, text: string, maxWidth: number, maxLines: number): string[]`, which word-wraps and ends the last line with `…` when the text overflows
    - `export function drawLeapCard(ctx: CanvasRenderingContext2D, card: LeapCardData): void`
    - `export async function downloadLeapCard(card: LeapCardData): Promise<void>`, which awaits `document.fonts.ready`, draws to an offscreen canvas, then uses `toBlob` and a temporary `<a download="ronin-leap-<slug>.png">`, where the slug is the lowercase `end` with non-alphanumerics replaced by `-` and is at most 40 characters long

The layout follows the spec order:
- Fonts: `--serif` Fraunces for the hook and end title, `--mono` DM Mono for the labels and footer, DM Sans for the body.
- Colours: hard-code the hex values of `--bg`, `--paper` and `--rust`, because canvas can't read CSS variables cheaply.
- Line limits: question 2, hook 3, end 2, reframe 3.
- The chain is a vertical rust line with a dot for each of the start, waypoints and end.

### Task 6: Leap editor in the recap view

**Files:**
- Create: `src/LeapEditor.tsx`
- Modify: `src/views.tsx` (`RecapView` gets the `readOnly` prop and the editor), `src/App.tsx:221` (pass `readOnly`), `src/styles.css` (editor styles that reuse the existing tokens)

**Interfaces:**
- Consumes: Task 5's `api.leaps`, `LeapCandidate`, `drawLeapCard`, `downloadLeapCard`, `CARD_WIDTH` and `CARD_HEIGHT`.
- Produces: `export function LeapEditor({ graph }: { graph: Graph })`, and `RecapView({ graph, readOnly, onBack })`.

How it works:
- **Eligibility,** computed client-side from `graph.nodes`: explored and depth ≥ 2, with depth found by walking `parent_id`.
- **Before eligibility:** a disabled **Find my leap** button with the text `Go one layer deeper to find a leap.`
- **Read-only:** the editor isn't rendered at all.
- **After clicking:** a loading state, then:
  - When `ranked` is true and there are candidates: tabs `Leap 1–3`, plus `Pick a node instead`.
  - When `ranked` is false or there are no candidates: the node picker is shown directly. It's a list of eligible node titles, and picking one calls `api.leaps(id, nodeId)`.
- **Editing:** hook and reframe `<textarea>`s, plus a checkbox per waypoint to hide it.
- **Preview:** a `<canvas width={1080} height={1350}>` scaled by CSS to fit, and redrawn with `drawLeapCard` on every edit.
- **Download PNG:** calls `downloadLeapCard`.
- **Errors:** the API error message, plus a Retry button.
- **`RANKING_ENABLED = true`:** a constant at the top of the file. When false, it always shows the picker (the fallback for Task 4's gate).
